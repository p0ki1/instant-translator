# 🎮 مترجم نصوص الألعاب - Game Translator

برنامج ترجمة فوري لنصوص الألعاب باستخدام OCR والذكاء الاصطناعي

## ✨ المميزات

- 🌍 دعم أكثر من 30 لغة
- ⚡ ترجمة فورية كل 5 ثوان
- 🎯 تحديد منطقة النص في اللعبة يدويًا
- 🖥️ نافذة عائمة للترجمة
- 🔄 تحديث الترجمة عند تغيير اللغة
- 🚀 سهل الاستخدام

## 📋 المتطلبات

### Windows
1. **Python 3.8+** - حمل من [python.org](https://www.python.org/downloads/)
2. **Tesseract OCR** - حمل من [GitHub](https://github.com/UB-Mannheim/tesseract/wiki)
3. **pip** - يأتي مع Python

### Linux
```bash
sudo apt-get install python3-pip tesseract-ocr
```

### macOS
```bash
brew install python3 tesseract
```

## 🚀 التثبيت والتشغيل

### الطريقة 1: تشغيل مباشر من Python (سهل)

**على Windows:**
```bash
run.bat
```

**على Linux/macOS:**
```bash
chmod +x run.sh
./run.sh
```

### الطريقة 2: تثبيت يدوي
```bash
# تثبيت المكتبات
pip install -r requirements.txt

# تشغيل البرنامج
python main.py
```

### الطريقة 3: بناء برنامج موثق (Executable)
```bash
python build_exe.py
```
سيتم إنشاء ملف تنفيذي في مجلد `dist/GameTranslator.exe`

## 📖 كيفية الاستخدام

1. **اختر لغة الترجمة:** من القائمة المنسدلة
2. **حدد منطقة النص:** اضغط "تحديد مساحة النص" واسحب على النص في اللعبة
3. **ابدأ الترجمة:** اضغط "ابدأ الترجمة"
4. **شاهد الترجمة:** ستظهر في نافذة عائمة

## ⚙️ الإعدادات

- **لغة OCR:** اكتب كود اللغة (مثل: `eng` للإنجليزية، `jpn` للاليابانية)
- **لغة الترجمة:** اختر من القائمة المتاحة
- **سرعة الترجمة:** كل 5 ثوانٍ تقريبًا

## 🛠️ استكشاف الأخطاء

### "لم أتعرف على نص واضح"
- كبّر منطقة النص المختارة
- تأكد من وضوح النص في اللعبة
- غيّر لغة OCR إذا كان النص بلغة أخرى

### "فشل الترجمة"
- تحقق من اتصال الإنترنت
- تأكد من أن كود اللغة صحيح
- حاول مرة أخرى بعد ثوانٍ

### Tesseract غير مثبت
**Windows:**
- حمل المثبت من [هنا](https://github.com/UB-Mannheim/tesseract/wiki)
- اتبع خطوات التثبيت

**Linux:**
```bash
sudo apt-get install tesseract-ocr
```

**macOS:**
```bash
brew install tesseract
```
